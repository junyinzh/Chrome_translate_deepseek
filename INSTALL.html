POWERED BY DEEPSEEK

安装，设置，开始阅读。

下载或克隆这个仓库，使用自己的 DeepSeek API Key。插件在本地运行，无需启动服务器。

  1. 打开 Chrome 的扩展管理页面。
    把下面的地址复制到 Chrome 地址栏：chrome://extensions
  2. 开启右上角的「开发者模式」，点击「加载已解压的扩展程序」。
    选择整个插件文件夹：Chrome_translate_deepseek/选择包含 manifest.json 的文件夹。
  3. 点击插件右上角的设置，填写自己的 DeepSeek API Key。
    点击「保存设置」，也可以用「测试连接」验证。已有本地配置时可以直接使用。
  4. 打开网页，点击 PageLingo，再点「翻译网页」。
    可以先从 Chrome 的拼图图标里把 PageLingo 固定到工具栏。翻译中关闭弹窗也会继续执行；网页右下角可以暂停或恢复原文。

更换 Key、选择模型或固定专业术语：点击插件弹窗右上角的设置按钮。
第一次使用建议打开普通文章页面。当前版本支持 HTML 网页，PDF 和图片文字暂不包含。

升级到 0.3.1：更新文件后，到 chrome://extensions 点击 PageLingo 的重新加载按钮，再刷新需要翻译的网页。已有 Key 和设置会保留，无需清空缓存。请使用 developemnt 分支的文件。更新后确认设置页版本为 v0.3.1，并将「同时翻译的批次」选择为 12 后保存；旧的并发设置会保留，新安装默认使用 12。刷新后，在插件弹窗勾选「点开链接后自动翻译」，首次开启时接受 Chrome 的网页访问授权。之后点击下一篇或在新标签页打开链接，就会自动翻译。关闭开关会暂停这组页面的翻译并保留已有译文。
